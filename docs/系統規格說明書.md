## 📋 系統概述

### 系統名稱
文檔庫（個人 Markdown 文件管理平台）

### 核心功能描述
提供單一使用者撰寫與管理 Markdown 文件的網頁工具，能夠：
1. 以 Markdown 撰寫文件，即時預覽，支援表格、待辦清單、程式碼區塊
2. 以最多三層的自訂分類（例：學習 › 課程 › 章節）加上自由標籤整理文件
3. 搜尋標題與內容，依標題／建立日期／最後更新排序
4. 匯入、下載 .md；轉出 PDF；以公開唯讀連結轉發給他人
5. 手機與電腦皆可使用，支援多種外觀主題

### 技術架構

| 分類 | 技術 | 版本／說明 |
|---|---|---|
| 前端框架 | Next.js（App Router、Turbopack） | 16.3.5（**注意：與舊版 Next.js 有破壞性差異**，寫程式前先查 `node_modules/next/dist/docs/`） |
| UI | React | 19.2.8 |
| 樣式 | 純 CSS＋CSS 變數（無 Tailwind） | `globals.css`（主題色）、`app.css`（版面）、`share-print.css`（轉發選單、列印） |
| 語言 | TypeScript | 5 |
| 後端 | Next.js Server Actions＋Server Components＋Route Handler | 無獨立後端服務 |
| ORM | Prisma 7（driver adapter 模式） | `@prisma/adapter-libsql` |
| 資料庫 | 本機 SQLite（`dev.db`）／正式 Turso（libSQL，AWS 東京） | 兩者獨立，不自動同步 |
| 登入 | Auth.js（NextAuth v5）Credentials | 帳密來自環境變數，JWT session（90 天） |
| Markdown | react-markdown＋remark-gfm | 不執行原始 HTML |
| PDF | 瀏覽器列印（`window.print()`）＋列印專用樣式 | 無伺服器端 PDF 套件 |
| 部署 | GitHub `main` → Vercel 自動部署（Functions 區域 hnd1） | |

## 🎯 功能需求規格

### F-001：登入與權限
- 路徑 `/login`，以 Email＋密碼登入（Credentials Provider）
- **單一帳號**：帳密來自環境變數 `ADMIN_EMAIL`／`ADMIN_PASSWORD`，以 `timingSafeEqual` 比對；資料庫沒有使用者資料表，資料不分使用者
- `src/proxy.ts` 攔截所有頁面，未登入一律導向 `/login?callbackUrl=…`
  - 例外（不需登入）：`/api/auth`、`/s/…`（公開分享頁）、靜態檔
- Server Action 一律先呼叫 `requireUser()`；下載 .md 的 Route Handler 自行檢查 `auth()`
- 修改帳密：改 `.env`（本機）與 Vercel 環境變數（正式）後重新部署

### F-002：導覽與共用版面
- 頂部：左側「📚 文檔庫」標題（回首頁），右側分頁 **文件、分類、⚙️ 設定**
- **全寬版面**：不設最大寬度，瀏覽器縮放或視窗拉寬時內容跟著撐滿；左右留白桌面 24px、手機 16px
- 斷點 760px：以下改為單欄（側欄在列表上方）
- **App 圖示**：`src/app/apple-icon.png`（180×180，iPhone 主畫面）、`src/app/icon.png`（512×512）、`src/app/favicon.ico`（16／32／48），圖案為靛藍底（`#4F46E5`）白色疊放文件；由 Next 檔案慣例自動產生 `<link>`。`src/proxy.ts` 的 matcher 排除 `icon`、`apple-icon`，圖示不需登入就能取得（否則 iPhone 加入主畫面會抓到登入頁）；更新圖示後 iPhone 需刪除舊捷徑、重新「加入主畫面」才會換圖。圖示原始檔與同系列的另兩個 app 圖示放在投資平台專案的 `docs/app-icons`（本機）

### F-003：文件列表（`/`）
- **側欄**：
  - 「全部」、分類樹（F-007）、「未分類」，各顯示文件數（上層分類的數字含所有子分類）
  - 有子分類者顯示 ▸／▾ 可展開收合；預設展開目前所選分類的上層路徑
  - 標籤雲：點標籤篩選，再點一次取消
  - **寬度可拖曳調整**：拖曳側欄右緣，範圍 180～560px（預設 240px）；雙擊恢復預設；聚焦時可用方向鍵調整；寬度存在 cookie `side_w`，伺服器端直接套用避免跳動；手機不顯示
  - 長名稱以「…」截斷，滑鼠停留顯示完整名稱
- **搜尋列**：搜尋標題與內容（`contains`），保留目前的分類／標籤／排序條件
- **列表欄位**：標題（＋摘要、標籤）｜分類｜建立日期｜最後更新
  - 欄位標題可點擊排序：標題（第一次 A→Z）、建立日期、最後更新（第一次新→舊），再點一次反轉，▲▼ 標示方向
  - 網址參數：`?cat=&tag=&q=&sort=title|created|updated&dir=asc|desc`；預設最後更新新→舊
  - 置頂文件永遠排在最前面
  - 分類欄只顯示最末層名稱，滑鼠停留顯示完整路徑
  - 手機：欄位改成標題下方一行小字（分類 · 建立 · 更新）
- 選上層分類時列出**該分類與所有子分類**的文件
- 「＋ 新文件」：若目前有選分類，新文件預設放在該分類

### F-004：文件檢視（`/docs/[id]`）
- 上方列：左「← 分類名稱」（回到該分類列表），右「＋ 新文件」（預設同一分類）
- 標題（置頂者前面加 📌）、分類完整路徑（每段可點）、標籤、更新／建立時間
- 操作按鈕：**✏️ 編輯、📌 置頂、複製（Markdown 原文）、⬇ .md、📄 PDF、↗ 轉發、刪除**
- 刪除需確認，刪除後回列表；無法復原
- 置頂、開關分享**不會**改變「最後更新」時間

### F-005：文件編輯（`/docs/new`、`/docs/[id]/edit`）
- **標題列**：標題輸入框＋「取消／返回檢視」「儲存」「儲存並檢視」按鈕（位於頁面上方，不需捲到底）
- 狀態列：「● 尚未儲存（Ctrl+S 儲存）」／「✓ 已儲存」＋字元數
- 欄位：分類（下拉選單依層級縮排）、標籤（逗號分隔，有既有標籤提示）、置頂
- **工具列**：H1／H2／H3、粗體、斜體、刪除線、行內程式碼、連結、項目清單、編號清單、待辦清單、引用、程式碼區塊、表格、分隔線
  - 行首類工具套用到選取的每一行，再按一次取消
- **檢視模式**：編輯／並排（預設）／預覽；手機不提供並排
- **快捷鍵**：`Ctrl+S` 儲存（留在編輯頁）、`Ctrl+B` 粗體、`Ctrl+I` 斜體、`Ctrl+K` 連結、`Tab` 插入兩個空白
- **清單自動延續**：在清單行按 Enter 自動帶出下一個符號（編號自動 +1、待辦變 `- [ ] `）；空項目按 Enter 結束清單；中文輸入法組字中不觸發
- **匯入 .md**：選擇 `.md／.markdown／.txt`；標題空白時，第一個 `# 標題` 當作文件標題，其餘為內容；已有內容時先確認是否取代
- 未儲存離開頁面時跳出瀏覽器提醒
- 新文件第一次儲存後網址改為 `/docs/<id>/edit`
- **限制**：標題 200 字、內容 500,000 字元、標籤最多 20 個、每個標籤 30 字

### F-006：下載與轉出 PDF
- **⬇ .md**（`/docs/[id]/download`）：內容為 `# 標題` ＋空行＋內文，`Content-Disposition` 以 UTF-8 檔名（標題移除 Windows 不允許字元，最長 80 字）
- **📄 PDF**：呼叫 `window.print()`，使用者在列印視窗選「另存為 PDF」
  - 列印期間把頁面標題暫時換成文件標題，作為預設檔名，列印結束後還原
  - 列印樣式（`share-print.css` 的 `@media print`）：隱藏導覽列、上方列、操作按鈕；強制白底黑字（暗色主題也一樣）；頁邊距 16mm×14mm；程式碼區塊、引用、表格列、圖片盡量不跨頁；標題不與下一段分離；程式碼自動換行

### F-007：分類（`/categories`）
- **最多三層**（`MAX_DEPTH = 3`，`src/lib/categoryTree.ts`），例：學習 › 課程 › 章節
- 同一層（同一個上層）內名稱不可重複，不同層可同名；名稱最長 30 字
- 顏色 8 種（`src/lib/colors.ts`：綠、藍、紫、粉、橘、紅、青、灰）；新增子分類預設沿用上層顏色
- 每列操作：**＋ 子分類**（第三層不顯示）、↑ ↓（同一層內排序）、✏️ 編輯、🗑 刪除
- **編輯**：名稱、顏色、**上層**（可把整個分類連同子分類搬到別處）
  - 上層選單自動排除：自己與自己的子孫、搬過去會超過三層的位置
  - 換到新的上層時排在最後
- **刪除**：子分類與文件**往上移一層**；第一層的分類刪掉後文件變成「未分類」。**不會刪除任何文件**
  - 若上一層已有同名分類，擋下並提示先改名或移走
- 文件只屬於一個分類（可為未分類）

### F-008：標籤
- 一份文件可有多個標籤；編輯時以逗號（全形／半形）、頓號或換行分隔，開頭的 `#` 會自動去掉
- 分類頁下方可**改名**與**刪除**標籤；改成已存在的名稱會**合併**
- 沒有任何文件使用的標籤在儲存／刪除文件時自動移除

### F-009：轉發（公開唯讀分享）
- 檢視頁「↗ 轉發」開啟選單：
  - 未分享：說明用途，按「建立分享連結」產生 token（`randomBytes(18)` → base64url，24 字元），存於 `Document.shareToken`
  - 已分享：顯示網址 `https://<網域>/s/<token>`，可**複製**、**LINE**（`line.me/R/share`）、**Email**（`mailto:`）、**更多…**（手機系統分享選單，`navigator.share`）、**預覽**
  - **停止分享**：確認後清除 token，舊連結立即失效；之後再分享會產生新網址
  - 分享中的文件按鈕顯示「轉發 · 分享中」
- **公開頁 `/s/[token]`**：不需登入；只顯示標題、內容、建立／更新時間與 PDF 按鈕；不顯示分類、標籤、編輯或其他文件
  - `robots: noindex, nofollow`；token 格式不符直接 404，不查資料庫
- 點外面或按 Esc 關閉選單；手機上選單改為固定在畫面底部

### F-010：外觀主題（`/settings`）
- 6 種：跟隨系統（預設）、清新綠、奶茶暖色、海洋藍、櫻花粉、夜間深色
- 選擇存於資料庫 `Setting`（key=`theme`）；切換時先改 `html[data-theme]` 立即生效再寫入
- **開發規則**：所有顏色一律使用 CSS 變數，不得直接寫色碼（分類顏色除外，由 `colors.ts` 統一管理，透過 `--c` 變數與 `color-mix()` 產生淡底）

| 用途 | CSS 變數 |
|---|---|
| 底色／卡片／框線 | `--bg`、`--card`、`--line` |
| 文字 | `--ink`、`--muted` |
| 主色 | `--accent`、`--accent-soft`、`--on-accent` |
| 警示／危險 | `--warn`、`--warn-soft`、`--holiday`（刪除、錯誤） |

- 設定頁另有登出

### F-011：環境設定（環境變數）
**本機**：`.env`；**正式站**：Vercel → Settings → Environment Variables（新增或修改後須**重新部署**才生效）

| 變數 | 用途 | 必要 |
|---|---|---|
| `DATABASE_URL` | 資料庫位址（本機 `file:./dev.db`／正式 `libsql://…`） | 是 |
| `DATABASE_AUTH_TOKEN` | Turso 權杖（僅正式站） | 正式站 |
| `AUTH_SECRET` | Session 簽章密鑰（本機與正式站不同） | 是 |
| `ADMIN_EMAIL`／`ADMIN_PASSWORD` | 登入帳密 | 是 |
| `REMOTE_DATABASE_URL`／`REMOTE_DATABASE_AUTH_TOKEN` | 本機 migration 腳本連正式資料庫用（只放本機 `.env`） | 維運時 |

- `.env*`（`.env.example` 除外）與 `*.db` 已加入 `.gitignore`，不可提交
- `.env.local` 由 `vercel link` 產生（`VERCEL_OIDC_TOKEN`），不需手動維護

### F-012：安全
- Markdown 不執行原始 HTML（react-markdown 預設），外部連結以新分頁開啟並加 `rel="noreferrer"`
- 所有寫入都經 Server Action 並先驗證登入；輸入在伺服器端截斷長度、驗證分類與顏色
- 公開分享只透過不可猜測的 token，可隨時撤銷；分享頁不洩漏其他文件或分類
- GitHub repo 設為私人

## 🗄️ 資料模型

定義於 `prisma/schema.prisma`。單一使用者，資料表不帶 `userId`。

| 資料表 | 主要欄位 | 說明 |
|---|---|---|
| Setting | key（主鍵）、value | 設定（目前只有 `theme`） |
| Category | name、color（預設 accent）、sort、parentId（自關聯，`onDelete: SetNull`）、createdAt | 分類樹，最多三層；同層名稱唯一由程式檢查 |
| Tag | name（唯一） | 標籤 |
| Document | title、content、categoryId（`onDelete: SetNull`）、tags（多對多）、pinned、shareToken（唯一，可為空）、createdAt、updatedAt | 文件 |
| _DocumentToTag | A（Document.id）、B（Tag.id） | Prisma 隱含的多對多關聯表 |

**索引**：`Category.parentId`、`Document.categoryId`、`Document.updatedAt`

**Migration 紀錄**：`init` → `share_link`（Document.shareToken）→ `category_tree`（Category.parentId，拿掉全域唯一名稱）

## 🎨 介面設計與體驗標準

### 整體風格
- 明亮、簡潔；卡片白底圓角、細框線；主色依主題變化
- 介面精簡，次要資訊收合或縮小（使用者偏好）
- 日期一律以台北時區顯示，數字使用等寬數字（`tabular-nums`）

### 響應式
- 所有頁面在 375px 寬度不可出現水平捲動
- 760px 以下：列表單欄、欄位改為小字列、編輯器不提供並排、轉發選單固定在底部
- 寬表格（Markdown 內）放在可水平捲動的容器內

### 新功能開發流程
1. 說明規劃（必要時先給模擬畫面）讓使用者確認，再實作
2. 實作後 `npx tsc --noEmit`、`npx eslint src`、`npx next build` 無錯誤
3. 可在本機瀏覽器驗證的部分實測（公開分享頁不需登入，可直接驗證）
4. 推送 `main` 自動部署，確認 Vercel 為 Ready

## 📊 品質標準

### 功能
- 刪除分類、搬移分類、改名合併標籤都不可造成文件遺失
- 分類樹計算（深度、路徑、子孫、合計數量）需有測試覆蓋；改動 `categoryTree.ts` 後重跑

### 效能
- 一般頁面 2 秒內載入；Vercel Functions 與 Turso 同在東京
- 列表一次載入全部符合條件的文件（個人用量）；文件數量大幅增加時再考慮分頁

### 資料安全
- 正式站資料只存在 Turso；建議定期匯出備份到本機
- **資料庫結構變更時**：
  1. 修改 `schema.prisma`，在 `prisma/migrations/<時間戳>_<名稱>/migration.sql` 手寫 SQL（`prisma migrate dev` 在非互動環境無法執行）
  2. 本機 `npx prisma migrate deploy`，再以 `npx prisma migrate diff --from-config-datasource --to-schema prisma/schema.prisma --script` 確認為空
  3. **不要用 SQLite 重建資料表的寫法**（`DROP TABLE` 再改名）：`Document.categoryId` 為 `SetNull`，重建 `Category` 可能清空所有文件的分類；一律改用 `ALTER TABLE … ADD COLUMN`
  4. 先備份相關資料，再以 `npm run db:migrate-remote -- <migration 資料夾名>` 只套用該一個 migration（**不帶名稱會全部重跑**）
  5. 確認正式資料完整後才推送程式碼
- 不在程式碼或文件中寫入任何金鑰、權杖、密碼

## 📌 已知限制

- PDF 依賴瀏覽器列印，版面會因瀏覽器略有差異；無法自動批次轉出
- 搜尋為簡單字串比對（SQLite `LIKE`），不支援模糊搜尋、權重排序；英文不分大小寫，中文需完全符合
- 單一帳號，沒有多人協作或權限分級；分享連結只能唯讀
- 不支援上傳圖片；圖片需使用外部網址
- 文件沒有版本歷史，覆寫後無法還原舊內容
- 本機與正式站資料庫不同步；本機與正式站目前使用同一組登入帳密
